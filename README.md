## 🔧 Environment Variables

The model's behavioral guardrails are controlled entirely via environment flags. Modify with extreme caution:

* `STRICT_SAFETY=FALSE`: Disables standard corporate AI lecturing. The model will not say "As an AI language model, I cannot..." Instead, it will say, "I am looking into this."
* `COFFEE_DEPENDENCY=HIGH`: Speeds up token generation by 20% but increases dry humor in output summaries.
* `OPTIMIZE_FOR_HUMINT=TRUE`: Prioritizes psychological profiling over boring factual summaries.
